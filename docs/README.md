# Docs

## Visão Geral

A pasta `docs` contém toda a documentação da aplicação. Este diretório serve como repositório central de informações técnicas, guias de uso e especificações do projeto.

## Objetivo

Fornecer documentação completa e organizada para:

- Facilitar a compreensão da arquitetura do projeto
- Auxiliar novos desenvolvedores no onboarding
- Documentar APIs e endpoints
- Esclarecer fluxos de negócio
- Manter guias de instalação e configuração
- Registrar decisões técnicas e padrões

## Estrutura de Arquivos

Exemplos de arquivos e pastas que podem estar neste diretório:
