# Frontend

## Visão Geral

A pasta `frontend` contém toda a interface de usuário da aplicação. Este diretório é responsável por renderizar a experiência do usuário, comunicar-se com o backend através de APIs e gerenciar o estado da aplicação no lado do cliente.

## Objetivo

Desenvolver uma interface responsiva e intuitiva que permita aos usuários:

- Acessar as funcionalidades da aplicação
- Visualizar e gerenciar dados
- Autenticar-se no sistema
- Interagir com recursos da aplicação
- Renderizar conteúdo dinamicamente
- Gerenciar estado da aplicação

## Estrutura de Arquivos

A pasta contém as seguintes subpastas:

- **`assets/`** - Imagens, ícones, fontes e outros recursos estáticos
- **`css/`** - Estilos e folhas de estilo
- **`js/`** - Scripts JavaScript e lógica do cliente

## Exemplos de Arquivos

```
frontend/
├── index.html             # Página principal
├── package.json           # Dependências e configuração Node.js
├── assets/
│   ├── images/           # Imagens do projeto
│   ├── icons/            # Ícones
│   └── fonts/            # Fontes customizadas
├── css/
│   ├── style.css         # Estilos globais
│   ├── responsive.css    # Estilos responsivos
│   └── components/       # Estilos de componentes
├── js/
│   ├── main.js           # Script principal
│   ├── api.js            # Comunicação com API
│   ├── components/       # Componentes JavaScript
│   ├── services/         # Serviços do cliente
│   └── utils/            # Funções utilitárias
└── README.md             # Documentação do frontend
```
